# Мобильный ЕБЦ

Приложение для поиска по выгрузке Ф18: поиск одной строкой, карточка ЭО, приборы учёта, транзит, карта договоров и карта подстанций. Работает на телефоне и на ПК, после первой загрузки — без интернета (без сети не грузится только подложка карты).

Данные в этом репозитории **не хранятся**. База загружается на каждое устройство отдельно и остаётся только на нём.

## Что в папке

Все файлы лежат в корне, подпапок нет.

## 1. Выложить на GitHub Pages (один раз)

1. На github.com нажмите **New repository**, имя, например, `mobile-ebc`, тип **Public**, создайте.
2. На странице репозитория: **Add file → Upload files**, перетащите **все файлы из этой папки** (кроме README можно, но и с ним не страшно), нажмите **Commit changes**.
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты там же появится адрес вида `https://ваш-логин.github.io/mobile-ebc/`.

## 2. Указать папку на Яндекс Диске

1. На Яндекс Диске создайте папку, откройте к ней доступ по ссылке («Поделиться → Скопировать ссылку»).
2. На GitHub откройте `config.js` → карандаш (Edit) → вставьте ссылку в кавычки:
   `yandexFolderUrl: 'https://disk.yandex.ru/d/....',`
3. **Commit changes**. Ссылка на папку не меняется, когда вы заменяете файлы внутри неё.

## 3. Подготовить базу (каждый месяц)

Архив собирает геокодер (программа `ebc_geocoder`): Ф18 + коды ФИАС + папка с подстанциями → zip с паролем.
В архиве лежат Ф18 с колонками координат и все файлы подстанций `.geojson`. Положите архив в папку на Яндекс Диске.

- Без колонок координат (обычная Ф18) приложение работает, но «Карта договоров» будет неактивна.
- Если в новом архиве нет подстанций, на телефоне останутся подстанции из прошлой загрузки.
- Файлы подстанций **не выкладывайте на GitHub** — в них ФИО и телефоны. Они только в архиве с паролем.

## 4. Установить на телефон

1. Откройте адрес из шага 1 в Chrome.
2. Меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
3. В приложении: **Скачать с Яндекс Диска** → скачать архив → вернуться → **Загрузить файл** → выбрать архив → ввести пароль.

## Как обновлять код

Замените файлы в репозитории новыми и подождите 2–3 минуты. На телефоне откройте приложение с интернетом — оно возьмёт свежие файлы; если нет — «База данных» → «Обновить приложение». Если меняется что-то кроме `config.js`, увеличьте номер в строке `CACHE` в `sw.js`.

## Что уже умеет

- Поиск одной строкой: договор, номер ЭО, счётчик, ИНН, наименование, адрес («красноармейская 7»).
- Результаты по ЭО с приборами учёта внутри строки; карточка ЭО с разделами, долгое нажатие — копирование.
- Транзит: транзитодатели и транзитоприёмники со ссылками друг на друга.
- **Карта договоров**: ЭО оранжевыми точками (примерные — пунктиром), кружки с числом издалека; подстанции с уровня района (переключатель «Подстанции»), легенда по «i»; нажатие на ЭО — кратко и «Открыть карточку»; несколько ЭО в одном доме — списком; «Без координат: N» — список.
- **Показать на карте** в карточке ЭО — сразу на уровне улицы с меткой.
- **Карта подстанций**: поиск по номеру (список по мере ввода, точные сверху, участок в подписи), нажатие — приближение и полное описание; телефоны в описании нажимаются.
- **Поиск на карте договоров** — как на главной; ЭО без координат в списке серые, открывают карточку.
- **Моё местоположение**: отдельная кнопка-прицел под «+/−», синяя точка. Координаты не покидают телефон.
- **Окошко снизу** закрывается смахиванием вниз за полосу сверху.
- **Уточнение местоположения**: в карточке ЭО — «Уточнить местоположение» (по GPS на объекте или указать на карте).
  Точка сразу видна на этом телефоне с пометкой «на проверке». «База данных» → «Отправить уточнения» → MAX:
  уходит файл `utochneniya_….csv`. После проверки в геокодере точка приходит всем со следующей базой.
- Работает без интернета; напоминает, если база старше 35 дней.
