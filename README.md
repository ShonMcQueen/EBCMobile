# Мобильный ЕБЦ — этап 1

Приложение для поиска по выгрузке Ф18: поиск одной строкой, карточка ЭО, приборы учёта, транзитодатели и транзитоприёмники. Работает на телефоне и на ПК, после первой загрузки — без интернета.

Данные в этом репозитории **не хранятся**. База загружается на каждое устройство отдельно и остаётся только на нём.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | страница и оформление |
| `app.js` | логика: поиск, карточка, транзит |
| `worker.js` | распаковка zip с паролем и разбор CSV в фоне |
| `zip.min.js` | библиотека для zip с паролем (zip.js) |
| `config.js` | **ваши настройки**: ссылка на папку Яндекс Диска |
| `sw.js` | работа без интернета |
| `manifest.webmanifest`, `icon-*.png` | установка на телефон, иконка |
| `LiberationSerif-Regular.ttf`, `LiberationSerif-Bold.ttf` | шрифт приложения (работает и без интернета) |
| `LICENSE-LiberationFonts.txt` | лицензия шрифта (бесплатный, SIL OFL) — держите рядом с файлами шрифта |

Все файлы лежат в корне, подпапок нет.

## 1. Выложить на GitHub Pages (один раз)

1. На github.com нажмите **New repository**, имя, например, `mobile-ebc`, тип **Public**, создайте.
2. На странице репозитория: **Add file → Upload files**, перетащите **все файлы из этой папки** (кроме README можно, но и с ним не страшно), нажмите **Commit changes**.
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты там же появится адрес вида `https://ваш-логин.github.io/mobile-ebc/`.

## 2. Указать папку на Яндекс Диске

1. На Яндекс Диске создайте папку, откройте к ней доступ по ссылке («Поделиться → Скопировать ссылку»).
2. На GitHub откройте `config.js` → карандаш (Edit) → вставьте ссылку в кавычки:
   `yandexFolderUrl: 'https://disk.yandex.ru/d/....',`
3. **Commit changes**. Ссылка на папку не меняется, когда вы заменяете файлы внутри неё.

## 3. Подготовить базу (каждый месяц)

1. В 7-Zip: правой кнопкой по CSV → **7-Zip → Добавить к архиву**.
2. Формат **zip**, в блоке «Шифрование» введите пароль, метод **AES-256**. ОК.
3. Положите архив в папку на Яндекс Диске (старый можно удалить).

Совет: оставляйте в имени файла месяц в виде `08.2026` — приложение покажет его как «база август 2026».

## 4. Установить на телефон

1. Откройте адрес из шага 1 в Chrome.
2. Меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
3. В приложении: **Скачать с Яндекс Диска** → скачать архив → вернуться → **Загрузить файл** → выбрать архив → ввести пароль.

## Как обновлять код

Замените файлы в репозитории новыми. Телефон подхватит новую версию сам: при следующем открытии с интернетом скачает её в фоне, а применит со второго запуска. Если меняется что-то кроме `config.js`, увеличьте номер в первой строке `sw.js` (`mobile-ebc-v1` → `mobile-ebc-v2`).

## Что уже умеет

- Поиск одной строкой: договор, номер ЭО, счётчик, ИНН, наименование, адрес; несколько слов ищутся вместе.
- Результаты по ЭО (вариант А) с приборами учёта внутри строки.
- Карточка ЭО: разделы-аккордеоны, все приборы учёта, долгое нажатие на значение — копирование.
- Транзит: у транзитодателя — список транзитоприёмников со ссылками, у транзитоприёмника — ссылка на транзитодателя; «сироты» помечены.
- Понимает и старый формат выгрузки (76 колонок, май), и новый (70 колонок, июль–август): колонки ищутся по названию.
- Работает без интернета, напоминает, если база старше 35 дней.

## Изменения в версии 1.3

- Шрифт Liberation Serif встроен в приложение.
- Тип прибора учёта — в мужском роде: «Расчётный», «Транзитный» (1.3.1).
- В выдаче каждый ЭО — отдельная карточка.
- Плашки транзита: голубые — про транзитодателя, оранжевые — про транзитоприёмников (цвета МЭС).
- В карточке транзитодателя свои расчётные ПУ развёрнуты, транзитные — в свёрнутом разделе «ПУ транзитоприёмников».
- В карточке транзитоприёмника ссылка на транзитодателя — только в голубом блоке вверху.
- На главной убран заголовок «Кого или что ищем?».
